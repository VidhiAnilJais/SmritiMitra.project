# 🧠 SmritiMitra

## AI-Powered Cognitive Care Companion

SmritiMitra is a cognitive care platform designed to support individuals with memory and cognitive challenges in managing their daily routines, engaging in cognitive activities, preserving memories, and staying connected with caregivers.

The platform provides a simple, accessible, and user-friendly digital environment where users can access cognitive games, medicine reminders, memory activities, an AI companion, and caregiver insights.

---

## ✨ Features

### 🏠 Smart Dashboard
A centralized dashboard that provides an overview of:

- Cognitive activity
- Medicine completion
- Daily activities
- Quick access to all features

---

### 🎮 Cognitive Games

Interactive cognitive activities designed to support:

- Memory
- Attention
- Recognition
- Cognitive engagement

Game performance can later be tracked and stored for progress monitoring.

---

### ❤️ Memory Journey

A personalized memory space where users can explore and preserve meaningful memories such as:

- Childhood
- School days
- Family memories
- Marriage
- Festivals and traditions

This feature can later support image and memory uploads.

---

### 💊 Medicine Management

Helps users manage their daily medicines by providing:

- Medicine schedules
- Medicine status
- Taken reminders
- Remind later option

Future versions can include automated notifications.

---

### 🎙️ AI Companion

SmritiMitra includes an interactive companion that helps users with questions related to:

- Medicines
- Daily routine
- Memory activities
- General assistance

The current version uses rule-based responses and voice recognition.

Future versions can integrate an AI/LLM API.

---

### 👨‍👩‍👧 Caregiver Dashboard

Caregivers can monitor important activity information including:

- Cognitive performance
- Medicine adherence
- Daily activities
- Engagement streak
- AI-generated observations

The system is designed to support dynamic patient information in future backend integration.

---

- Name

- Caregiver connection

## 🎯 Problem Statement

Individuals with cognitive and memory-related challenges may face difficulties in remembering medicines, maintaining daily routines, engaging in cognitive activities, and staying connected with their caregivers and loved ones.

**SmritiMitra** aims to provide a centralized digital companion that supports:

- 🧠 Cognitive engagement
- 💊 Daily medicine management
- ❤️ Memory preservation
- 🎙️ Interactive assistance
- 👨‍👩‍👧 Caregiver monitoring

The platform focuses on creating a simple, accessible, and supportive environment for cognitive care.

---

## ⚠️ Disclaimer

SmritiMitra is a **cognitive care support platform** and is not intended to provide:

- Medical diagnosis
- Medical treatment
- Emergency medical advice

Any AI-generated observations or insights are provided for informational purposes only and should not replace advice from qualified healthcare professionals.
